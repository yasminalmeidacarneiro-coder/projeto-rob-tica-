Módulo 1: LED Fade-in — Iluminação Suave

Problematização: Mudanças bruscas de luz causam desconforto e ofuscamento em pessoas com baixa visão[cite: 1]. O efeito Fade-in permite transições suaves para orientação espacial em ambientes internos[cite: 1].

Conceitos Técnicos: Portas PWM (pinos 3, 5, 6, 9, 10, 11), função analogWrite(), laço for() e incremento de brilho[cite: 1].

Componentes: Arduino Uno R3, Protoboard, LED 5mm, Resistor 220Ω, Jumpers[cite: 1].

Código-Fonte (Arduino IDE):

// Protótipo: LED Fade-in para Iluminação Suave de Acessibilidade
// Aula 23/24 - Robótica Educacional
const int pinoLED = 11; // Pino PWM conectado ao LED

void setup() {
  pinMode(pinoLED, OUTPUT);
}

void loop() {
  // Efeito Fade-in: aumenta o brilho gradualmente (0 a 255)
  for (int brilho = 0; brilho <= 255; brilho++) {
    analogWrite(pinoLED, brilho);
    delay(15); // Transição suave para maior conforto visual
  }
  // Efeito Fade-out: diminui o brilho gradualmente (255 a 0)
  for (int brilho = 255; brilho >= 0; brilho--) {
    analogWrite(pinoLED, brilho);
    delay(15);
  }
}

Módulo 2: LED RGB — Alerta Visual de Emergência

Problematização: Em emergências com pouca visibilidade, placas tradicionais não são suficientes[cite: 1]. Luzes dinâmicas indicam perigo (vermelho) ou rotas seguras (azul)[cite: 1].

Conceitos Técnicos: Sistema RGB, controle de brilho/velocidade via Potenciômetro (entrada analógica A0), modulação PWM[cite: 1].

Componentes: Arduino Uno, LED RGB, Potenciômetro, Resistores 220Ω, Protoboard, Jumpers[cite: 1].

Código-Fonte (Arduino IDE):

// Protótipo: Sinalizador de Emergência RGB com Potenciômetro
// Aula 28 - Código Gerado/Refinado com Auxílio do Gemini
const int pinoRed = 9;   // Controle da cor Vermelha (Perigo)
const int pinoBlue = 10;  // Controle da cor Azul (Rota Segura)
const int pinoPot = A0;   // Potenciômetro para controle de velocidade/brilho

void setup() {
  pinMode(pinoRed, OUTPUT);
  pinMode(pinoBlue, OUTPUT);
  pinMode(pinoPot, INPUT);
}

void loop() {
  int valorPot = analogRead(pinoPot);
  int tempoPisca = map(valorPot, 0, 1023, 100, 1000); // Mapeia leitura para delay em ms

  // Estado 1: Alerta de Perigo (Vermelho pisca)
  digitalWrite(pinoRed, HIGH);
  digitalWrite(pinoBlue, LOW);
  delay(tempoPisca);

  // Estado 2: Sinalização de Rota Segura (Azul pisca)
  digitalWrite(pinoRed, LOW);
  digitalWrite(pinoBlue, HIGH);
  delay(tempoPisca);
}

Módulo 3: Arco-íris Visual — Relógio Cognitivo por Cores

Problematização: Relógios convencionais dificultam a interpretação do tempo[cite: 1]. O sistema associa cores aos períodos do dia (Manhã = Azul, Tarde = Verde, Noite = Vermelho)[cite: 1].

Conceitos Técnicos: Uso de millis() para cronometragem não-bloqueante, alternância de estados e misturas de cores RGB[cite: 1].

Componentes: Arduino Uno, LED RGB, Resistores 220Ω, Protoboard, Jumpers[cite: 1].

Código-Fonte (Arduino IDE):

// Protótipo: Relógio Visual Cognitivo por Cores (Sem bloqueio por delay)
// Aula 30 - Auxílio IA Gemini
const int pinoR = 9;
const int pinoG = 10;
const int pinoB = 11;

unsigned long tempoAnterior = 0;
const long intervalo = 5000; // Altera a cada 5 segundos (simulação de período)
int estadoPeriodo = 0; // 0: Manhã, 1: Tarde, 2: Noite

void setup() {
  pinMode(pinoR, OUTPUT);
  pinMode(pinoG, OUTPUT);
  pinMode(pinoB, OUTPUT);
}

void setColor(int r, int g, int b) {
  analogWrite(pinoR, r);
  analogWrite(pinoG, g);
  analogWrite(pinoB, b);
}

void loop() {
  unsigned long tempoAtual = millis();
  if (tempoAtual - tempoAnterior >= intervalo) {
    tempoAnterior = tempoAtual;
    estadoPeriodo = (estadoPeriodo + 1) % 3;
  }

  switch(estadoPeriodo) {
    case 0: setColor(0, 0, 255); break; // Manhã: Azul
    case 1: setColor(0, 255, 0); break; // Tarde: Verde
    case 2: setColor(255, 0, 0); break; // Noite: Vermelho
  }
}

Módulo 4: Semáforo Inclusivo — Formas Geométricas + Cores

Problematização: Pessoas com daltonismo têm dificuldade de identificar apenas cores[cite: 1]. A solução associa formas geométricas físicas (Vermelho = Quadrado, Amarelo = Triângulo, Verde = Círculo)[cite: 1].

Conceitos Técnicos: Sequenciamento lógico de LEDs, temporização e integração maker com maquete[cite: 1].

Componentes: Arduino Uno, 3 LEDs, 3 Resistores 220Ω, Maquete recortada com símbolos[cite: 1].

Código-Fonte (Arduino IDE):

// Protótipo: Semáforo Inclusivo para Daltonismo e Baixa Visão
// Aula 32 - Verde (Círculo), Amarelo (Triângulo), Vermelho (Quadrado)
const int ledVerde = 8;
const int ledAmarelo = 9;
const int ledVermelho = 10;

void setup() {
  pinMode(ledVerde, OUTPUT);
  pinMode(ledAmarelo, OUTPUT);
  pinMode(ledVermelho, OUTPUT);
}

void loop() {
  // SINAL VERDE: Liberação (Círculo)
  digitalWrite(ledVerde, HIGH);
  digitalWrite(ledAmarelo, LOW);
  digitalWrite(ledVermelho, LOW);
  delay(5000);

  // SINAL AMARELO: Atenção (Triângulo)
  digitalWrite(ledVerde, LOW);
  digitalWrite(ledAmarelo, HIGH);
  digitalWrite(ledVermelho, LOW);
  delay(2000);

  // SINAL VERMELHO: Pare (Quadrado)
  digitalWrite(ledVerde, LOW);
  digitalWrite(ledAmarelo, LOW);
  digitalWrite(ledVermelho, HIGH);
  delay(5000);
}

Módulo 5: Sensor PIR — Orientação Espacial Sonora/Luminosa

Problematização: Identificação automatizada de presença em corredores para guiar pessoas com deficiência visual por alertas sonoros e luz[cite: 1].

Conceitos Técnicos: Leitura digital do Sensor PIR, acionamento de Buzzer, variação PWM e feedback Serial[cite: 1].

Componentes: Arduino Uno, Sensor PIR, Buzzer, LED, Resistor 220Ω, Protoboard, Jumpers[cite: 1].

Código-Fonte (Arduino IDE):

// Protótipo: Assistente de Passagem com PIR e Sinalização Auditiva/Visual
// Aula 34 - Integração Sensor de Presença + Buzzer + Serial
const int pinoPIR = 2;
const int pinoBuzzer = 8;
const int pinoLED = 9;

void setup() {
  pinMode(pinoPIR, INPUT);
  pinMode(pinoBuzzer, OUTPUT);
  pinMode(pinoLED, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int presenca = digitalRead(pinoPIR);

  if (presenca == HIGH) {
    Serial.println("Presença detectada! Acionando alertas...");
    digitalWrite(pinoBuzzer, HIGH);
    for (int i = 0; i <= 255; i += 5) {
      analogWrite(pinoLED, i);
      delay(10);
    }
    delay(1000);
    digitalWrite(pinoBuzzer, LOW);
  } else {
    digitalWrite(pinoBuzzer, LOW);
    digitalWrite(pinoLED, LOW);
  }
}

Módulo 6: Detector MQ-2 — Alerta Sonoro Frequencial

Problematização: Detectores comuns usam luzes pequenas[cite: 1]. Este protótipo utiliza variação na frequência de bipes sonoros conforme a concentração de gás[cite: 1].

Conceitos Técnicos: Leitura analógica do MQ-2, categorização de faixas de risco e variação de frequência[cite: 1].

Componentes: Arduino Uno, Sensor MQ-2, Buzzer, Protoboard, Jumpers[cite: 1].

Código-Fonte (Arduino IDE):

// Protótipo: Detector Inclusivo de Gás MQ-2 com Bipes Multinivel
// Aula 36 - Alerta Sonoro Proporcional ao Perigo
const int pinoMQ2 = A0;
const int pinoBuzzer = 8;

void setup() {
  pinMode(pinoMQ2, INPUT);
  pinMode(pinoBuzzer, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int nivelGas = analogRead(pinoMQ2);
  Serial.print("Nível de Gás: ");
  Serial.println(nivelGas);

  if (nivelGas < 300) {
    // Nível Seguro: Sem alarme
    digitalWrite(pinoBuzzer, LOW);
  } else if (nivelGas >= 300 && nivelGas < 600) {
    // Alerta Médio: Bipes lentos
    digitalWrite(pinoBuzzer, HIGH);
    delay(300);
    digitalWrite(pinoBuzzer, LOW);
    delay(300);
  } else {
    // Perigo Alto: Bipes rápidos e contínuos
    digitalWrite(pinoBuzzer, HIGH);
    delay(80);
    digitalWrite(pinoBuzzer, LOW);
    delay(80);
  }
}
